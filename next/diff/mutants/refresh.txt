# Refresh requests for the carried-over mutation run of the full engine (scripts/mutants.sh with
# MUTANTS_ITERATE=1, which the integration branch's CI runs on every push).
#
# Carry-over trusts earlier results: a mutant once caught is not tested again while its code is
# unchanged. Deleting or weakening a test can turn such a mutant into a survivor without changing
# its code. When a change deletes or weakens tests, add one line here per engine file whose
# mutants those tests caught, as
#
#   <date> <glob>
#
# with the glob relative to next/ as cargo-mutants names files (`mega-evm2/src/tx.rs`; a glob with
# a slash matches the whole path, one without the file name; `all` for every file). The next
# carried-over run drops the carried results of the matching files, so they are tested again
# without carry-over; the run records the line and never applies it again. To refresh the same
# files again later, add a new line with a new date. Lines may be removed once applied.
